Panduan Setup Google Sheets Real-Time

1
Buat Google Sheets — nama tab: PUBGM
Buka sheets.google.com, buat spreadsheet baru. Klik kanan tab bawah → rename jadi PUBGM.
Isi baris 1 sebagai header, baris 2 dst sebagai data tim:
A(id) B(name) C(alive) D(kills) E(rank) 1 TEAM ALPHA 4 3 2 2 TEAM BRAVO 0 7 1 3 TEAM CHARLIE 2 5 3 ...hingga 20 tim
alive: 0–4 (jumlah pemain hidup). alive=0 → otomatis status DEAD.
2
Buka Apps Script & paste kode Code.gs
Di Google Sheets: menu Extensions → Apps Script.
Hapus semua kode yang ada. Paste isi file Code.gs yang sudah didownload. Tekan Ctrl+S.
3
Deploy sebagai Web App
Klik Deploy → New Deployment → pilih type: Web App.
Execute as : Me (email kamu) Who has access: Anyone
Klik Deploy → Authorize access → pilih akun Google → Allow.
Copy Web App URL yang muncul (dimulai dengan https://script.google.com/...).
⚠️ Setiap kali edit Code.gs, harus Deploy ulang agar perubahan aktif!
4
Paste URL ke Dashboard → Hubungkan
Paste URL tadi ke kolom 📊 Google Sheets di bagian atas dashboard → klik 🔗 Hubungkan.
Jika berhasil, badge 🟢 Google Sheets Aktif muncul. Data sync otomatis tiap 10 detik.
5
Cara pakai saat match berlangsung
Operator cukup edit Google Sheets langsung (bisa dari HP/laptop lain).
Dalam ≤10 detik, semua overlay OBS otomatis update.

• Tim mati → alive = 0
• Update kills → edit kolom kills
• Update posisi → edit kolom rank
• Baris diupdate dari Sheets akan berkedip biru di ticker
• Tab 💀 Eliminated tetap klik manual untuk trigger animasi pop-up
